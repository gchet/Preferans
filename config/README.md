# Параметры интерфейса

Редактируйте `interface.json`, затем пересоберите приложение обычным скриптом:

```powershell
.\build.ps1 -Target All
```

Параметры с окончанием `Ms` — положительные целые числа в миллисекундах: 1000 мс = 1 секунда.
Параметры с окончанием `Px` — размеры в пикселях. Масштабы и отношения допускают дробные числа.
Файл встраивается в Windows и Android при сборке; менять его на устройстве после установки не требуется.

| Параметр | Назначение |
|---|---|
| noticeDurationMs | Время показа всплывающего сообщения |
| roundSummaryDurationMs | Время показа «Запись за раздачу» |
| cardFlightDurationMs | Длительность движения карты после отпускания |
| cardDropTimeoutMs | Предельное ожидание подтверждения перемещения карты |
| cardDecodeTimeoutMs | Предельное ожидание подготовки рисунков карт |
| uiPollIntervalMs | Интервал обновления состояния интерфейса |
| botTickIntervalMs | Интервал проверки действий ботов и переходов игры |
| nextTrickDelayMs | Пауза перед уборкой взятки или следующей раздачей |
| dragStartDistancePx | На сколько нужно сдвинуть указатель, чтобы начать перетаскивание |
| dragClickSuppressionMs | Подавление случайного клика после перетаскивания |
| buttonCancelDistancePx | Смещение пальца, отменяющее подсветку касания кнопки |
| buttonFeedbackDurationMs | Продолжительность визуального подтверждения нажатия |
| wideLayoutMinHeightPx | Минимальная высота для подбора размеров карт в широком окне |
| cardMinHeightPx / cardMaxHeightPx | Минимальная и максимальная высота основных карт |
| cardViewportWidthRatio | Ограничение высоты карты относительно ширины окна |
| ownCardScale | Размер собственных карт относительно карт остальных игроков |
| sideHeightScaleThree / sideHeightScaleFour | Место для боковых рук при подборе размеров карт на 3/4 игроков |
| cardStairMinPx / cardStairMaxPx | Пределы вертикальной «лесенки» боковых карт |
| cardStairViewportRatio | Смещение «лесенки» относительно ширины окна |
| layoutVerticalReservePx | Запас высоты для подписей и промежутков при подборе карт |
| discardGapPx | Запас промежутка возле области сноса |
| cardFanEdgePaddingPx | Горизонтальный запас при расчёте перекрытия карт |
| miniCardSizePx | Размер квадратных вспомогательных карт последней взятки |
| miniCardFontSizePx / miniCardRankSizePx | Размеры масти и достоинства вспомогательных карт |
| roomServiceURL | Адрес службы комнат; переменная PREFERANS_ROOMS_URL имеет приоритет |
| roomRequestTimeoutMs | Время ожидания ответа службы комнат |
| roomPollIntervalMs | Интервал получения состояния комнаты |
| roomOnlineTimeoutMs | Через какое время без ответа показывать отсутствие связи с комнатой |
| heartbeatIntervalMs | Интервал проверки связи с игроками |
| connectionSilenceTimeoutMs | Допустимое время молчания игрового канала |
| reconnectRetryMs | Интервал повторной попытки после неудачного подключения |
| handshakeRetryMs | Ожидание перед повтором при продолжающемся согласовании связи |
| answerRetryMs | Ожидание перед повтором при отсутствии ответа участника |

Переходы игры выполняются на очередной проверке, поэтому фактическая пауза может быть длиннее на величину `botTickIntervalMs`.

Этот файл задаёт фиксированные параметры сборки. Настройки конкретного пользователя и договорённости стола по-прежнему изменяются в приложении и сохраняются в его каталоге данных. Пароли в этот JSON не записывайте.
Подробное оформление элементов остаётся в CSS, языковые тексты — в `locales/ru.json`.
Для применения изменений не используйте `-SkipWeb`: параметры читаются и Go, и WebUI.
