# Преферанс
[English](README.md)

Игра для Windows и Android на трёх или четырёх участников по ленинградским соглашениям. Можно играть без интернета с локальными ботами или подключаться к комнате через собственные серверы сигналинга и TURN.

## Возможности
- Общий WebUI, игровой движок на Go, оболочки Windows WebView2 и Android WebView.
- Комнаты, автоматическое подключение и восстановление связи, голосовой чат.
- Настраиваемые договорённости стола, локальные боты и необязательные облачные ИИ-боты.
- Сохранение незавершённых партий ведущего, история комнаты и итоги игроков.
- Украинский язык по умолчанию, русский и английский; три редактируемые SVG-колоды.

Реализован только Ленинград. Сочи, Классика и Ростов оставлены для будущих версий.

## Сборка
Нужны PowerShell 7, Go (версия в go.mod), Node.js и Zig для Windows. Для Android — JDK 17, Android SDK и NDK. Gradle запускается через включённый Wrapper.

Из корня проекта:
~~~powershell
pwsh ./build.ps1 -Target All -Public -AI Off
~~~
Результат: dist/Preferans.exe, dist/Preferans.apk и dist/version.json. Для Windows нужен WebView2 Runtime; для Android — Android 8+ и ARM64. APK пока сохраняет существующую debug-подпись.

Публичная сборка не содержит адресов личного сервера. Настройте свой сервер комнат и TURN в приложении или включите **Только игра с ботами (без интернета)**. Общедоступный сервер проектом не предоставляется. Личные значения разработчика задаются в игнорируемом project.local.json.
