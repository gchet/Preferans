# Локализация

Единственный редактируемый источник текстов для каждой языковой версии:

- `locales/ru.json` — русский;
- `locales/uk.json` — украинский, язык по умолчанию;
- `locales/en.json` — английский.

Переключатель UK / RU / EN находится слева в шапке всех экранов и в заголовке диалоговых окон. Язык сохраняется в `appearance.json`, поле `language` (`ru`, `uk`, `en`). Отсутствующее значение означает украинский, независимо от языка ОС. Выбор локален для устройства и не меняет язык других участников.

Локальный HTTP-сервер передаёт язык в атрибуте `data-language` исходного HTML до загрузки модулей. Это работает и после перезапуска, когда порт HTTP меняется. После выбора языка WebUI перезагружается, подключаясь к тому же backend и текущей партии. Незавершённые изменения открытой формы не сохраняются автоматически. Android синхронизирует язык системных уведомлений через WebView-мост; заголовок окна Windows обновляется через нативный мост.

## Как устроено

JSON — плоский словарь стабильных ключей. Префиксы `web.`, `go.` и `android.` обозначают место использования; это разделы одного файла, а не отдельные каталоги платформ. Ключи после первоначального переноса не следует перенумеровывать. Для новых текстов используйте понятные смысловые имена, например `web.room.join_failed`.

WebUI импортирует JSON при сборке. Go встраивает те же файлы через `go:embed` в пакет `preferans/locales`. Gradle автоматически копирует JSON в assets APK и получает из русского каталога название приложения. Android читает эти assets; отдельные редактируемые копии `strings.xml` не нужны. Существующая команда `build.ps1 -Target All` остаётся прежней.

Изменение текста требует пересборки соответствующего приложения. Внешние файлы рядом с EXE/APK не нужны.

## Подстановки

Для WebUI и Android используются `{p0}`, `{p1}` и т. д. Номер не всегда начинается с нуля: при переносе сохранены позиции выражений исходного шаблона. Сохраняйте имена параметров; их можно переставлять в переводе. Значение вставляется один раз, без повторной обработки содержимого имени игрока.

Сообщения Go сохраняют стандартные параметры `fmt`: `%s`, `%d`, `%v`, `%w` и другие. Сохраняйте их количество, тип и порядок. `%w` сохраняет исходную ошибку для `errors.Is`/`errors.As`.

HTML, CSS и идентификаторы команд остаются в коде. Не добавляйте HTML в переводы. Для HTML-подстановок сохраняется прежнее экранирование динамических значений в вызывающем коде. Не переводите имена игроков, названия комнат, адреса, пароли, протокольные значения и сохранённые пользовательские данные.

Общий игровой state, сообщения Go и журналы на диске сохраняют стабильные русские тексты. WebUI локализует известные сообщения при показе: ошибки, журнал на экране и подписи раздач. Это исключает зависимость данных остальных участников от языка ведущего. Сохранённые файлы не изменяются. Генерируемые названия ботов переводятся только у объектов с `bot: true`; пользователь с похожим именем сохраняет своё имя. Алиасы моделей и их ответы не переводятся. Язык промптов ИИ выбирается отдельно.

Рисунки и обозначения на SVG-картах являются частью колод и не меняются через языковые файлы. Технические сообщения сторонних библиотек и системных диалогов также не входят в каталог.

## Проверка

`node scripts/check-locales.mjs` проверяет полный набор ключей во всех трёх языках, подстановки и отсутствие HTML. Проверка автоматически запускается при сборке WebUI. Новый ключ необходимо добавить во все три каталога. Runtime fallback на русский остаётся для неизвестных языков и диагностических ситуаций.

Тесты: `go test ./locales ./internal/...` и `npm test` из каталога `web`. `web/tests/i18n.spec.ts` проверяет переводы сообщений и сохранение пользовательских данных. Тест `rooms: local language selection` проверяет выбор во всех трёх языках, сохранение после перезагрузки, окна настроек/правил и игровой экран на планшете и телефоне. Остальные UI-тесты явно выбирают русский для проверки прежних сценариев.
